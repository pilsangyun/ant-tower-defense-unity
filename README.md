# Ant Tower Defense Unity (앤트 가디언즈 Unity 포팅)

HTML5 웹 기반 개미 타워 디펜스 게임(`ant-tower-defense`)을 Unity 6 (6000.6.7f1) 엔진으로 1:1 완벽 포팅한 프로젝트입니다.

## 주요 기능 및 구현 시스템
- **픽셀 퍼펙트 UI & 뷰포트**: 540x860 해상도 모바일 뷰, LetterboxCamera 종횡비 보정.
- **원본 16종 스프라이트 시트 연동**: 불개미, 산성개미, 병정개미, 일개미, 페로몬개미, 자폭개미 및 달팽이, 무당벌레, 독거미, 보스 몬스터 등 256x256 원본 고해상도 일러스트 적용.
- **3단계 특화 진화 분기 모달**: 2단계 업그레이드 후 원본과 동일한 [A] / [B] 분기 선택 모달(타이틀, 능력치 설명, 비용) 팝업 및 실시간 외형 교체(철갑개미 흑철 뿔투구 전사, 꿀단지개미 큰뿔 전사) 및 발 밑 회전 진화 오라 링 연출.
- **10초 자동 웨이브 카운트다운**: 웨이브 준비 시간 동안 상단 HUD에 실시간 초 카운트다운 표기, 0초 시 자동 시작 및 [N] 단축키 지원.
- **실시간 유도 투사체 비행**: 32x32 방사형 화염구 및 개미산 구체가 타겟을 향해 실시간 궤적으로 날아가 피격/데미지 판정.

## 요구 사양 및 실행 방법
- Unity Editor: **Unity 6 (6000.6.7f1)** 이상
- 프로젝트 경로: `My project/`
- 메인 씬: `Assets/Scenes/SampleScene.unity`
